about

I'm Amy, known as thehuglet online. I'm a low-level systems programmer with a track record of building robust software from the ground up. I have experience with Rust, Zig, C, Python and Java.

I have worked professionally on Dungeon Now Loading, a popular mod for the game Minecraft with over 11 million combined downloads. My work there included implementing gameplay features and playtesting.

I created germterm, a terminal software rendering library with features you're unlikely to find elsewhere, such as alpha compositing, sub-pixel drawing and a 2D particle system.

I'm currently building Project Neyon, a 2D space shooter game written from scratch in Zig. The game runs on a custom ECS, has a custom 2D physics implementation and a dedicated OpenGL compute and rendering pipeline for 2D particles.
